\section{Introduction}
\label{sec:intro}

Federated Learning (\textbf{FL}) enables distributed edge clients to collaboratively train neural network models without sharing private local data~\cite{mcmahan2017communication,kairouz2021advances}. In practical deployments on resource-constrained embedded and mobile nodes, collaborative learning faces three key challenges spanning data heterogeneity, edge hardware limits, and adversarial attacks.

First, local datasets across participating edge devices are non-independent and identically distributed (\textbf{non-IID}), frequently exhibiting severe label skew~\cite{hsu2019measuring}. Under such heterogeneity, standard global consensus methods such as FedAvg~\cite{mcmahan2017communication} and FedProx~\cite{li2020federated} suffer from \textit{client drift}, where local updates pull shared parameters in conflicting directions, degrading performance on specialized edge nodes~\cite{li2020fair}.

Second, while personalized FL has been developed to mitigate client drift, existing methods often introduce high on-device computational and memory costs. Dual-model architectures (such as Ditto~\cite{li2021ditto}) maintain concurrent global and personalized network instances on each device, roughly doubling model parameters, backpropagation memory, and peak VRAM. On the other hand, head-decoupling frameworks such as FedRep~\cite{collins2021exploiting} split learning into a shared feature backbone and private local classifier heads; however, isolated local heads do not collaborate with peers and can easily overfit when local training samples are scarce.

Third, adversarial model poisoning and Byzantine failures pose serious threats in distributed networks~\cite{blanchard2017machine,yin2018byzantine,fang2020local}. Standard robust aggregators (such as Multi-Krum~\cite{blanchard2017machine}, coordinate-wise median, and trimmed mean) evaluate model updates in the full Euclidean parameter space. When data is non-IID, honest updates from specialized clients naturally point in different directions from the average update. As a result, standard Euclidean distance filters often mistakenly reject honest specialized clients while failing to filter subtle coordinated attacks.

To address these challenges, we observe that edge clients benefit from a multi-tier representation hierarchy: a global model captures features common across all clients, cluster-level models pool knowledge among peer devices with similar label distributions, and local heads provide private adaptation tailored to each device. To avoid the memory overhead of maintaining separate neural networks for each tier, we design a unified framework where all three tiers share a single feature backbone.

We introduce \textbf{\fedhep{}} (\textit{Federated Hierarchical Ensemble Personalization}), an efficient framework designed for heterogeneous edge clients. Our key contributions are:

\noindent\textbf{Single-Backbone Three-Tier Hierarchy}: We design an architecture where a single shared feature extractor feeds three linear classification tiers: a global consensus Root head ($W_r$), a collaborative cluster Parent head ($W_p$), and a private Local head ($W_l$), avoiding redundant feature extractors and minimizing on-device memory.

\noindent\textbf{Active-Class Logit Masking (ACLM) \& Skew-Calibrated Weighting}: We introduce ACLM to mask unobserved categories during training on cluster and local heads. This mathematically eliminates negative gradient updates from classes a client does not possess, while a continuous Bernstein polynomial weighting scheme balances the contribution of each tier based on local label skew.

\noindent\textbf{Privacy-Preserving Peer Clustering}: Clients discover collaborative peer clusters using low-dimensional Random Projections (RP) grounded in the Johnson-Lindenstrauss lemma~\cite{johnson1984extensions,woodruff2014sketching}, grouping clients by functional update similarity without transmitting raw local parameters or label counts.

\noindent\textbf{Layered Subspace Byzantine Defense}: We develop a defense combining Subspace-Constrained Cosine Filtering (\textbf{SCCF}), which measures update alignment strictly on each client's observed classes, adaptive backbone update norm-bounding, and multi-round Temporal Trust Tracking (\textbf{TTT}).

\noindent\textbf{Empirical Evaluation}: We evaluate FedHEP on edge-budgeted subsamples of CIFAR-100 and FEMNIST across five Dirichlet non-IID regimes ($\alpha \in \{0.05, 0.1, 0.5, 1.0, \infty\}$) and 50-client scaling under partial participation. We compare against 6 state-of-the-art baselines across 4 adversarial attack vectors, and profile on-device runtime on MobileNetV3 to confirm memory and latency efficiency.
