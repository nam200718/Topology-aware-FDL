\section{Introduction}
\label{sec:intro}

Federated Learning (\textbf{FL}) has emerged as the preeminent paradigm for privacy-preserving distributed machine learning, enabling massively distributed edge clients to collaboratively train neural models without centralizing raw telemetry~\cite{mcmahan2017communication,kairouz2021advances}. In realistic deployments on resource-constrained embedded nodes (e.g., IoT sensors, autonomous micro-agents, mobile edge devices), multiagent collaborative learning encounters a fundamental \textit{trilemma} spanning statistical heterogeneity, edge hardware boundaries, and adversarial threats.

First, real-world edge data distributions across participating nodes are fundamentally non-independent and identically distributed (\textbf{non-IID}), frequently exhibiting severe label skew. Under such distribution shifts, conventional consensus aggregation schemes such as \textsc{FedAvg}~\cite{mcmahan2017communication} and \textsc{FedProx}~\cite{li2020federated} suffer from severe \textit{client drift}, where gradient updates pull the shared parameters toward orthogonal local optima, catastrophic forgetting ensues, and tail performance across specialized nodes collapses.

Second, while personalized FL has been proposed to overcome client drift, existing formulations incur prohibitive on-device overheads. Dual-model architectures (such as \textsc{Ditto}~\cite{li2021ditto}) maintain concurrent global and local network instances, virtually doubling parameter footprint, forward-backward graph allocations, and peak VRAM usage on hardware-constrained edge nodes. Conversely, head-decoupling frameworks like \textsc{FedRep}~\cite{collins2021exploiting} bifurcate representation learning into disjoint global backbone and local head phases, yet leave local heads isolated from peer collaboration and prone to overfitting on sparse local support.

Third, the threat of Byzantine failures and adversarial model poisoning presents a critical failure mode in distributed multiagent systems~\cite{blanchard2017machine,yin2018byzantine}. Standard Byzantine-robust aggregation rules (e.g., Multi-Krum~\cite{blanchard2017machine}, coordinate-wise median, and trimmed mean) compute global geometric distances in the unconstrained parameter space. Under extreme label skew, honest updates from highly specialized clients exhibit legitimate angular deviations that standard Euclidean filters conflate with malicious poisoning, erroneously penalizing honest nodes while admitting stealthy in-distribution adversaries.

\paragraph{Our Contributions.} To resolve this trilemma, we present \textbf{\fedhep{}} (\textit{Federated Hierarchical Ensemble Personalization}), an efficient framework designed for resource-constrained multiagent edge topologies. The main contributions of this work are summarized as follows:
\begin{itemize}
    \item \textbf{Single-Backbone 3-Tier Representation Hierarchy}: We design an architecture where a single shared feature extractor concurrently feeds three linear classification tiers: a global consensus head ($H_g$), a collaborative cluster head ($H_c$), and a local private head ($H_l$), completely eliminating parameter and memory duplication.
    \item \textbf{Interference Mitigation via ACLM \& Skew-Calibrated Weighting}: We introduce Active-Class Logit Masking (\textbf{ACLM}) and an anchored dynamic binomial loss weighting scheme, eliminating negative backpropagation drag from unobserved labels onto the shared feature extractor.
    \item \textbf{Privacy-Preserving Dynamic Peer Clustering}: Clients dynamically identify collaborative clusters via low-dimensional Random Projections (\textbf{RP}, $m=256$) bounded by the Johnson-Lindenstrauss lemma~\cite{johnson1984extensions}, clustering clients by functional similarity without exposing raw local gradients.
    \item \textbf{Layered Subspace Byzantine Defense}: We develop a multi-tier defense combining Subspace-Constrained Cosine Filtering (\textbf{SCCF}) restricted strictly to each client's observed class support, backbone update norm-bounding, and multi-round Temporal Trust Tracking (\textbf{TTT}).
    \item \textbf{Rigorous Empirical Validation}: Through extensive benchmarks on CIFAR-100 across five Dirichlet non-IID regimes ($\alpha \in [\infty, 0.05]$) and 50-client scaling, we demonstrate superior average accuracy and worst-decile tail fairness against 6 competitive baselines, resilient defense across 4 Byzantine poisoning vectors, and minimal edge footprint on MobileNetV3.
\end{itemize}
