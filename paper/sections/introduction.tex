\section{Introduction}
\label{sec:intro}

Federated Learning (\textbf{FL}) enables distributed edge clients to collaboratively train neural network models without sharing private local data~\cite{mcmahan2017communication,kairouz2021advances}. In practical deployments on resource-constrained embedded and mobile nodes, collaborative learning faces three key challenges spanning data heterogeneity, edge hardware limits, and adversarial attacks.

First, local datasets across edge nodes are non-independent and identically distributed (\textbf{non-IID})---departing from independent and identically distributed (\textbf{IID}) data---with severe label skew~\cite{hsu2019measuring}. Under this heterogeneity, global methods like Federated Averaging (FedAvg)~\cite{mcmahan2017communication} and FedProx (Federated Proximal)~\cite{li2020federated} suffer from \textit{client drift}, where conflicting updates degrade accuracy on specialized nodes~\cite{li2020fair}.

Second, while personalized FL mitigates client drift, existing schemes incur high on-device memory costs. Dual-model architectures (e.g., Ditto~\cite{li2021ditto}) maintain concurrent global and personalized networks per device, doubling parameters, backpropagation activations, and peak video random-access memory (\textbf{VRAM}). Split-head frameworks such as FedRep (Federated Representation Learning)~\cite{collins2021exploiting} decouple a shared backbone from private classifier heads; however, isolated local heads do not collaborate with peers and are prone to overfitting when local samples are scarce.

Third, adversarial model poisoning and Byzantine failures pose serious threats in distributed networks~\cite{blanchard2017machine,yin2018byzantine,fang2020local}. Standard robust aggregators (such as Multi-Krum~\cite{blanchard2017machine}, coordinate-wise median, and trimmed mean) evaluate model updates in the full Euclidean parameter space. When data is non-IID, honest updates from specialized clients naturally point in different directions from the average update. As a result, standard Euclidean distance filters often mistakenly reject honest specialized clients while failing to filter subtle coordinated attacks.

To address these challenges, we observe that edge clients benefit from a multi-tier representation hierarchy: a global model captures features common across all clients, cluster-level models pool knowledge among peer devices with similar label distributions, and local heads provide private adaptation tailored to each device. To avoid the memory overhead of maintaining separate neural networks for each tier, we design a unified framework where all three tiers share a single feature backbone.

We introduce \textbf{\fedhep{}} (\textit{Federated Hierarchical Ensemble Personalization}), an efficient framework designed for heterogeneous edge clients. Our key contributions are:

\noindent\textbf{Single-Backbone Three-Tier Hierarchy}: We design an architecture where a single shared feature extractor feeds three linear classifier head weight matrices spanning $C$ classes for $d$-dimensional embeddings: a global Root head ($W_r \in \mathbb{R}^{d \times C}$), a cluster Parent head ($W_p \in \mathbb{R}^{d \times C}$), and a private Local head ($W_l \in \mathbb{R}^{d \times C}$), avoiding redundant backbones and minimizing edge memory.

\noindent\textbf{ACLM and Skew-Calibrated Weighting}: We introduce Active-Class Logit Masking (\textbf{ACLM}) to mask unobserved categories on cluster and local heads, suppressing gradient corruption from absent classes on personalized heads, while Bernstein polynomials balance each tier's loss contribution based on local label skew.

\noindent\textbf{Privacy-Preserving Peer Clustering}: Clients discover collaborative peer clusters using low-dimensional Random Projections (RP) grounded in the Johnson-Lindenstrauss (JL) lemma~\cite{johnson1984extensions,woodruff2014sketching}, grouping clients by functional update similarity without transmitting raw local parameters or label counts.

\noindent\textbf{Layered Subspace Byzantine Defense}: We develop a defense combining Subspace-Constrained Cosine Filtering (\textbf{SCCF}), measuring update alignment on observed classes, adaptive backbone update norm-bounding, and multi-round Temporal Trust Tracking (\textbf{TTT}).

\noindent\textbf{Empirical Evaluation}: We evaluate FedHEP on edge-budgeted Federated Extended MNIST (FEMNIST) and CIFAR-100 across five Dirichlet non-IID regimes with concentration parameter $\alpha \in \{0.05,$ $0.1,$ $0.5,$ $1.0,$ $\infty\}$ ($\alpha=\infty$ denotes balanced IID) and 50-client scaling under partial participation. We compare against 6 representative baselines across 4 attack vectors, and profile simulated runtime on MobileNetV3 to evaluate edge efficiency.
