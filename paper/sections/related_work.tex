\section{Related Work}
\label{sec:related}

\subsection{Personalized Federated Learning}
To mitigate client drift arising from non-IID data distributions, numerous personalized federated learning strategies have been proposed. Consensus-regularization techniques, such as \textsc{FedProx}~\cite{li2020federated} and \textsc{SCAFFOLD}~\cite{karimireddy2020scaffold}, enforce proximity constraints or variance-reduced control variates to stabilize global convergence. However, these methods still enforce a monolithic consensus hypothesis that inherently limits adaptation on skewed local marginals. Meta-learning formulations such as \textsc{Per-FedAvg}~\cite{fallah2020personalized} train an initial meta-model tailored for quick post-hoc adaptation, but require second-order gradient calculations during training.

Dual-model methods, epitomized by \textsc{Ditto}~\cite{li2021ditto}, decouple global objective tracking from local personalization by maintaining two complete concurrent network instances per client. While offering robust formal guarantees, duplicating deep backbones on embedded micro-controllers quickly breaches VRAM and compute budgets. Head-decoupling methods, notably \textsc{FedRep}~\cite{collins2021exploiting}, freeze the classifier head while training the backbone and vice versa. However, \textsc{FedRep} isolates the personalized head entirely from peer collaboration, preventing nodes with overlapping class support from pooling representational power. \hepfl{} bridges this gap by unifying global, cluster, and local heads over a single shared backbone.

\subsection{Byzantine Robustness in Federated Learning}
Distributed learning systems in adversarial multiagent environments are vulnerable to Byzantine poisoning attacks, including label flipping, sign flipping, adversarial gradient ascent, and additive Gaussian noise~\cite{blanchard2017machine,yin2018byzantine}. Classical robust aggregation operators—such as coordinate-wise trimmed mean, coordinate-wise median~\cite{yin2018byzantine}, and distance-based outlier filters like Multi-Krum~\cite{blanchard2017machine}—implicitly assume that honest client updates are concentrated around a singular mean. 

In realistic non-IID multiagent topologies, legitimate statistical skew induces severe angular dispersion among honest updates. Standard geometric aggregators routinely misclassify honest specialized updates as Byzantine outliers, actively degrading system fairness. While data-bootstrapped methods like \textsc{FLTrust}~\cite{cao2021fltrust} attempt to resolve this via a central server dataset, collecting clean representative proxy data violates core edge privacy tenets. \hepfl{} resolves this dilemma by restricting cosine similarity checks strictly to observed active class subspaces (\textbf{SCCF}) and tracking multi-round reputation via \textbf{TTT}.

\subsection{Clustered Federated Learning}
Clustered FL algorithms group clients exhibiting congruent task distributions into discrete coalitions~\cite{sattler2020clustered,ghosh2020efficient}. For instance, \textsc{CFL}~\cite{sattler2020clustered} hierarchically bifurcates client populations based on cosine similarities of stationary gradients, whereas \textsc{IFCA}~\cite{ghosh2020efficient} uses loss-based cluster estimation. However, existing methods either require transmitting high-dimensional raw parameter gradients—which leaks private class distributions—or lack defenses against Byzantine adversaries deliberately perturbing cluster assignments. \hepfl{} uses low-dimensional Random Projections (\textbf{RP}) to preserve privacy and bounds geometric distortion via the Johnson-Lindenstrauss lemma.
