\section{Related Work}
\label{sec:related}

\paragraph{Personalized Federated Learning}
To combat non-IID client drift, personalized federated learning departs from monolithic consensus. Consensus regularization like FedProx~\cite{li2020federated} and SCAFFOLD (Stochastic Controlled Averaging)~\cite{karimireddy2020scaffold} stabilizes optimization via proximal terms or control variates, yet restricts clients to a single consensus model. Meta-learning such as Per-FedAvg (Personalized FedAvg)~\cite{fallah2020personalized} adapts a meta-model, but incurs costly Hessian computations. Dual-model architectures (e.g., APFL [Adaptive Personalized FL]~\cite{deng2020adaptive} and Ditto~\cite{li2021ditto}) decouple global and personalized objectives via two concurrent client networks, doubling parameter storage and backpropagation memory.

Head-decoupling formulations (e.g., FedPer [Personalization layers]~\cite{arivazhagan2019federated}, FedRep [Representation learning]~\cite{collins2021exploiting}, FedBABU [Body-Aggregation \& Bone-Updating]~\cite{oh2021fedbabu}, FedRoD [Robust Decoupled FL]~\cite{chen2022bridging}, and FedALA [Adaptive Local Aggregation]~\cite{zhang2023fedala}) split classifier heads from a shared backbone. However, localized heads remain isolated from peers. As shown in recent work~\cite{chen2022bridging} and our benchmarks (Section~\ref{sec:experiments}), scarce local data causes isolated heads to overfit under severe skew; conversely, on balanced IID data, they fail to learn the full label space without classifier aggregation.

\paragraph{Byzantine-Robust Aggregation under Heterogeneity}
Federated learning is vulnerable to adversarial poisoning, including label flipping, sign flipping, and gradient ascent~\cite{blanchard2017machine,yin2018byzantine,fang2020local,bhagoji2019analyzing,shejwalkar2021manipulating}. Classical robust aggregators---coordinate-wise median, trimmed mean~\cite{yin2018byzantine}, and Multi-Krum~\cite{blanchard2017machine}---assume honest client updates concentrate around a unimodal mean. Under non-IID skew, honest updates disperse angularly, causing standard Euclidean filters to misclassify specialized nodes as malicious. While proxy schemes like FLTrust~\cite{cao2021fltrust} avoid this via central data, collecting edge samples centrally violates decentralized privacy.

\paragraph{Clustered Learning and Dimensionality Reduction}
Clustered FL groups clients into discrete coalitions. Clustered FL (CFL)~\cite{sattler2020clustered} partitions clients by stationary gradient angles, while IFCA (Iterative Federated Clustering Algorithm)~\cite{ghosh2020efficient} clusters via loss minimization. However, existing methods either transmit raw gradients---risking class privacy---or lack defenses against Byzantine cluster manipulation. Meanwhile, Johnson-Lindenstrauss (JL) random projection sketching~\cite{johnson1984extensions,woodruff2014sketching} preserves pairwise metrics, but has not been integrated into hierarchical multi-tier personalization pipelines.

Unlike methods addressing personalization, Byzantine robustness, or efficiency in isolation, \fedhep{} unifies them into a single-backbone framework. Combining Active-Class Logit Masking (ACLM) with sketching for peer discovery and subspace-constrained filtering (SCCF), \fedhep{} demonstrates high personalization accuracy, outlier filtering under skew, and single-model edge memory efficiency.
