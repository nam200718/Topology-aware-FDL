\section{Related Work}
\label{sec:related}

\paragraph{Personalized Federated Learning.}
To combat client drift under non-IID statistical heterogeneity, personalized federated learning departs from monolithic global consensus. Consensus-regularization schemes like FedProx~\cite{li2020federated} and SCAFFOLD~\cite{karimireddy2020scaffold} stabilize optimization via proximal terms or control variates, yet still restrict clients to a single consensus hypothesis. Meta-learning frameworks such as Per-FedAvg~\cite{fallah2020personalized} train an initial meta-model for fast local adaptation, but incur computationally heavy second-order Hessian calculations. Interpolation and dual-model architectures (e.g., APFL~\cite{deng2020adaptive} and Ditto~\cite{li2021ditto}) decouple global and personalized objectives by maintaining two distinct concurrent networks per client, roughly doubling on-device parameter storage and backpropagation memory.

Head-decoupling formulations (e.g., FedPer~\cite{arivazhagan2019federated}, FedRep~\cite{collins2021exploiting}, FedBABU~\cite{oh2021fedbabu}, FedRoD~\cite{chen2022bridging}, and FedALA~\cite{zhang2023fedala}) decouple classifier heads from a shared representation backbone. However, in these architectures, localized heads remain strictly isolated from peer collaboration. As observed both in recent literature~\cite{chen2022bridging} and in our empirical benchmarks (Section~\ref{sec:experiments}), when local training data is scarce, isolated heads are prone to overfitting on narrow class subsets under severe skew; conversely, under balanced IID distributions, individual heads struggle to learn the full label space without global classifier aggregation.

\paragraph{Byzantine-Robust Aggregation under Heterogeneity.}
Federated learning systems are vulnerable to adversarial model poisoning, including label flipping, sign flipping, and gradient ascent~\cite{blanchard2017machine,yin2018byzantine,fang2020local,bhagoji2019analyzing,shejwalkar2021manipulating}. Classical robust aggregators---such as coordinate-wise median, trimmed mean~\cite{yin2018byzantine}, and distance-based geometric outlier filters like Multi-Krum~\cite{blanchard2017machine}---implicitly assume that honest client updates are concentrated around a unimodal mean. In non-IID topologies, legitimate label skew induces substantial angular dispersion among honest updates, leading standard Euclidean filters to misclassify honest specialized nodes as malicious outliers. While proxy-bootstrapped methods like FLTrust~\cite{cao2021fltrust} circumvent this via a central server dataset, collecting representative edge data on a central server violates core decentralized privacy principles.

\paragraph{Clustered Learning and Dimensionality Reduction.}
Clustered FL groups clients exhibiting similar data distributions into discrete coalitions~\cite{sattler2020clustered,ghosh2020efficient}. CFL~\cite{sattler2020clustered} recursively partitions populations based on cosine distances of stationary gradients, whereas IFCA~\cite{ghosh2020efficient} assigns clusters via loss minimization. However, existing methods either require transmitting high-dimensional raw parameter gradients---potentially leaking sensitive class distributions---or lack defenses against Byzantine adversaries manipulating cluster memberships. Meanwhile, Johnson-Lindenstrauss random projection sketching~\cite{johnson1984extensions,woodruff2014sketching} provides theoretical pairwise metric preservation, but has not been integrated into hierarchical multi-tier personalization pipelines.

Unlike existing methods that address personalization, Byzantine robustness, or efficiency in isolation, \fedhep{} integrates these capabilities into a unified single-backbone framework. By combining Active-Class Logit Masking (ACLM) with privacy-preserving sketching for peer discovery and subspace-constrained filtering (SCCF), \fedhep{} demonstrates strong personalization accuracy, robust outlier filtering under extreme label skew, and single-model edge memory efficiency.
