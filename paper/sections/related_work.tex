\section{Related Work}
\label{sec:related}

\paragraph{Personalized Federated Learning.}
To combat client drift under non-IID statistical heterogeneity, personalized federated learning departs from monolithic global consensus. Consensus-regularization schemes like FedProx~\cite{li2020federated} and SCAFFOLD~\cite{karimireddy2020scaffold} stabilize optimization via proximal terms or control variates, yet still restrict clients to a single consensus hypothesis. Meta-learning frameworks such as Per-FedAvg~\cite{fallah2020personalized} train an initial meta-model for fast local adaptation, but incur computationally heavy second-order Hessian calculations. Interpolation and dual-model architectures (e.g., APFL~\cite{deng2020adaptive} and Ditto~\cite{li2021ditto}) decouple global and personalized objectives by maintaining two distinct concurrent networks per client, effectively doubling on-device memory and gradient overhead. Head-decoupling formulations (e.g., FedPer~\cite{arivazhagan2019federated}, FedRep~\cite{collins2021exploiting}, FedBABU~\cite{oh2021fedbabu}, and FedALA~\cite{zhang2023fedala}) isolate classifier heads from a shared backbone, yet leave localized heads entirely decoupled from peer synergy, inducing representation collapse on uniform IID data and severe overfitting under extreme label sparsity.

\paragraph{Byzantine-Robust Aggregation under Heterogeneity.}
Distributed multiagent optimization is acutely vulnerable to adversarial model poisoning, including label flipping, sign flipping, and gradient ascent~\cite{blanchard2017machine,yin2018byzantine,fang2020local}. Classical robust aggregators---such as coordinate-wise median, trimmed mean~\cite{yin2018byzantine}, and distance-based geometric outlier filters like Multi-Krum~\cite{blanchard2017machine}---implicitly assume that honest client updates are concentrated around a unimodal mean. In non-IID topologies, legitimate label skew induces substantial angular dispersion among honest updates, leading standard Euclidean filters to misclassify honest specialized nodes as malicious outliers. While proxy-bootstrapped methods like FLTrust~\cite{cao2021fltrust} circumvent this via a central server dataset, collecting representative edge telemetry violates core decentralized privacy tenets.

\paragraph{Clustered Learning and Dimensionality Reduction.}
Clustered FL groups clients exhibiting congruent data distributions into discrete coalitions~\cite{sattler2020clustered,ghosh2020efficient}. CFL~\cite{sattler2020clustered} recursively partitions populations based on cosine distances of stationary gradients, whereas IFCA~\cite{ghosh2020efficient} assigns clusters via loss minimization. However, existing methods either require transmitting high-dimensional raw parameter gradients---leaking sensitive class distributions---or lack defenses against Byzantine adversaries intentionally manipulating cluster memberships. Meanwhile, Johnson-Lindenstrauss random projection sketching~\cite{johnson1984extensions} provides theoretical pairwise metric preservation, but has not been integrated into hierarchical multi-tier personalization pipelines.

\paragraph{Positioning of \fedhep{}.}
Unlike existing paradigms that address personalization, Byzantine robustness, or efficiency in isolation, \fedhep{} resolves this trilemma within a unified single-backbone framework. By combining Active-Class Logit Masking (ACLM) with privacy-preserving sketching for peer discovery and subspace-constrained filtering (SCCF), \fedhep{} simultaneously achieves Pareto-optimal personalization, robust outlier filtering under extreme label skew, and single-model edge efficiency.
