Core 01 • Model Architecture
Single-Backbone 3-Tier Representation Hierarchy
Abstract Khớp Code
Abstract Trích Dẫn
"...an architecture that coordinates three tiers of representation—global consensus, collaborative cluster, and local private heads—over a single shared feature extractor."
Code Mechanics & Tensor Flow

Mô hình MultiHeadResNet9 sử dụng chung feature extractor $f_\theta: \mathcal{X} \to \mathbb{R}^d$ ($d=256$).

Ba head phân loại tuyến tính độc lập: fc2_root ($W_r$), fc2_parent ($W_p$), fc2_local ($W_l$).

Features được trích xuất duy nhất một lần: $z = f_\theta(x)$. Tại eval time, logits được tổ hợp tuyến tính có kiểm soát độ phân tán nhiệt độ (Dynamic Logit Dispersion Temperature Matching).

Công thức biểu diễn tổ hợp logits tại bước suy luận của client $i$:

$$ \hat{y} = \arg\max_{c \in \{1, \dots, C\}} \left[ w_l \frac{W_l f_\theta(x)}{T_l} + w_p \frac{W_p f_\theta(x)}{T_p} + w_r \frac{W_r f_\theta(x)}{T_r} \right]_c $$

Core 02 • Representation Conditioning
Active-Class Logit Masking (ACLM)
Aligned
Abstract Trích Dẫn
"To mitigate gradient interference from unobserved labels, HEP-FL incorporates active-class logit masking and skew-calibrated loss weighting without duplicating network parameters."
Code Mechanics & Tensor Flow

Mỗi client sở hữu tập nhãn quan sát được $\mathcal{Y}_i \subset \{1, \dots, C\}$.

Tại updater.py:L828-838, các logits của lớp chưa từng xuất hiện ($c \notin \mathcal{Y}_i$) được gán giá trị $-10^9$ trước khi tính CrossEntropyLoss.

Điều này làm $\text{Softmax}(\tilde{z})_c \to 0$, triệt tiêu gradient đạo hàm $\frac{\partial \mathcal{L}}{\partial z_c} = p_c - y_c = 0$, ngăn chặn hiện tượng làm méo mó các vector trọng số lớp vắng mặt.

Đề Xuất Công Thức Cho Paper (LaTeX)

Hàm mất mát phân loại có điều kiện nhãn hỗ trợ:

$$ \mathcal{L}_{\text{ACLM}}(\mathbf{z}_i, y; \mathcal{Y}_i) = -\log \frac{\exp(z_{i, y})}{\sum_{c' \in \mathcal{Y}_i} \exp(z_{i, c'})}, \quad \forall y \in \mathcal{Y}_i $$
$$ \nabla_{W_{c, :}} \mathcal{L}_{\text{ACLM}} = \mathbf{0}, \quad \forall c \notin \mathcal{Y}_i $$
LaTeX Source Copy
\mathcal{L}_{\text{ACLM}}(\mathbf{z}_i, y; \mathcal{Y}_i) = -\log \frac{\exp(z_{i, y})}{\sum_{c' \in \mathcal{Y}_i} \exp(z_{i, c'})}, \quad y \in \mathcal{Y}_i

Đảm bảo tính chất triệt tiêu gradient trên nhãn vắng mặt: $\nabla_{W_{c, :}} \mathcal{L}_{\text{ACLM}} = \mathbf{0}, \forall c \notin \mathcal{Y}_i$.

Core 03 • Dynamic Loss Partition
Anchored Dynamic Binomial Loss Weighting (Partition of Unity)
Aligned
Abstract Trích Dẫn
"...incorporates active-class logit masking and skew-calibrated loss weighting without duplicating network parameters."
Code Mechanics & Tensor Flow

Đo lường độ lệch entropy phân bố nhãn địa phương $R_{skew} = \frac{\exp(H(p_i)) - 1}{C - 1} \in [0, 1]$.

Áp dụng hệ số neo an toàn $a_i = \max\left(\frac{1}{2K}, \frac{|\mathcal{Y}_i|}{C}\right)$ tránh hiện tượng cắt đứt kết nối với Root head ở edge devices cực đoan.

Phân rã nhị thức: $\lambda_r = a_i + (1-a_i)R_{skew}^2$, $\lambda_p = 2R_{skew}(1-R_{skew})$, $\lambda_l = (1-R_{skew})^2$.

Đề Xuất Công Thức Cho Paper (LaTeX)

$$ \mathcal{L}_i = \alpha_r \mathcal{L}_r + \alpha_p \mathcal{L}_p + \alpha_l \mathcal{L}_l, \quad \sum_{k \in \{r, p, l\}} \alpha_k = 1.0 $$
$$ \alpha_k = \frac{\lambda_k}{\sum_j \lambda_j}, \quad \begin{cases} \lambda_r = a_i + (1 - a_i) R_{skew}^2 \\ \lambda_p = 2 R_{skew} (1 - R_{skew}) \\ \lambda_l = (1 - R_{skew})^2 \end{cases} $$

Core 04 • Privacy-Preserving Clustering
Random Orthogonal Parameter Sketch Clustering (JL Lemma)
Aligned
Abstract Trích Dẫn
"Clients dynamically identify collaborative clusters through low-dimensional random projections of model updates, preserving data privacy."
Code Mechanics & Tensor Flow

Thay vì gửi phân bố nhãn thô (vi phạm riêng tư), client gom cụm dựa trên vector cập nhật $\Delta \mathbf{w}_i \in \mathbb{R}^D$ ($D \approx 300,000$).

Mã nguồn chiếu $\Delta \mathbf{w}_i$ qua ma trận ngẫu nhiên $\Phi \in \mathbb{R}^{D \times 256}$ sinh từ phân phối Gaussian trực giao $\mathcal{N}(0, 1/m)$.

Vector 256 chiều được chuẩn hóa L2 và phân cụm bằng K-Means cosine distance.

Đề Xuất Công Thức Cho Paper (LaTeX)

Định lý Johnson-Lindenstrauss bảo toàn khoảng cách góc:

$$ \mathbf{s}_i = \frac{\Phi^T \Delta \mathbf{w}_i}{\|\Phi^T \Delta \mathbf{w}_i\|_2} \in \mathbb{R}^m, \quad \Phi_{jk} \sim \mathcal{N}\left(0, \frac{1}{m}\right), \; m=256 $$
$$ (1 - \epsilon)\|\Delta \mathbf{w}_i - \Delta \mathbf{w}_j\|_2 \le \|\mathbf{s}_i - \mathbf{s}_j\|_2 \le (1 + \epsilon)\|\Delta \mathbf{w}_i - \Delta \mathbf{w}_j\|_2 $$
LaTeX Source Copy
\mathbf{s}_i = \frac{\Phi^T \Delta \mathbf{w}_i}{\|\Phi^T \Delta \mathbf{w}_i\|_2} \in \mathbb{R}^m, \quad \Phi_{jk} \sim \mathcal{N}\left(0, \frac{1}{m}\right), \; m=256

Bảo đảm sai số méo góc cosine: $(1-\epsilon)\|\Delta \mathbf{w}_i - \Delta \mathbf{w}_j\|_2 \le \|\mathbf{s}_i - \mathbf{s}_j\|_2 \le (1+\epsilon)\|\Delta \mathbf{w}_i - \Delta \mathbf{w}_j\|_2$.

def _random_project(vectors: np.ndarray, target_dim: int = 256, seed: int = 42) -> np.ndarray:
    if vectors.shape[1] <= target_dim:
        return vectors
    rng = np.random.RandomState(seed)
    D = vectors.shape[1]
    projection = rng.randn(D, target_dim) / np.sqrt(target_dim)
    return vectors @ projection
